# HSK語彙（1級–6級）

日本語で HSK 1級から 6級の語彙を学ぶ静的ページです。サーバーは要りません。`index.html` をブラウザで開いてください。

級のボタンで、いま学ぶ級を一つ選びます。「単語」と「練習」は別の画面です。練習画面では三つの問題形式を切り替えられます。練習の出題と選択肢は選んだ級の語です。検索では必要に応じて全級から探せます。

「学習設定」で再生速度を0.5～1.5倍に変更できます。初めて使う HSK 1–2 はピンインを表示し、HSK 3–6 は非表示です。自分で表示を切り替えた場合は、その設定をすべての級で優先します。日本語訳は初期状態で表示です。表示設定は単語一覧と補助情報に適用され、問題に必要な題文と選択肢は常に表示されます。設定はこのブラウザに保存されます。

単語は中国語・ピンイン・日本語訳で検索できます。`zuotian` のように声調や空白を省いたピンインでも検索でき、検索結果の件数を表示します。検索内容は画面を切り替えても級ごとに保持されます（ページを再読み込みすると解除されます）。検索結果を聞いたり学習済みにしたりしても、もとの学習位置は変わりません。検索をクリアすると元のグループと位置へ戻ります。「すべての級」を選ぶと級ラベル付きで検索でき、「ここから学ぶ」を押した場合だけその単語へ学習位置を移します。

単語一覧の「並び順・絞り込み」内の「表示順」で「ピンイン順」か「ランダム順」を選べます。初期状態は声調を区別しないピンイン順です。選んだ表示順はこのブラウザに保存されます。ランダム順は級ごとに保持され、検索や画面の切り替えで変わりません。「再シャッフル」で並べ直せます。ページを再読み込みしても同じランダム順で続けられます。

練習は三つです。

- 意味を選ぶ：中国語を見て、日本語の意味を四つから選ぶ
- 中国語を選ぶ：日本語を見て、中国語を四つから選ぶ
- ピンインを選ぶ：中国語を見て、ピンインを四つから選ぶ

通常の練習は1回10問です。最後に「結果を見る」を押すと正解数と間違えた単語を確認でき、音声を聞いて復習できます。「もう一度、10問」で次の練習を始めます。

学習位置・級・練習の回答と得点はこのブラウザに保存されます。単語を調べたり、別の級や問題形式に切り替えたりしても、戻ると前の練習を続けられます。再読み込み後は前回の画面が開き、「続きから学ぶ」で学習位置へ移動できます。練習を最初からやり直す場合は「新しく10問を始める」を押し、確認してから始めます。

単語一覧は20語ずつのグループで表示します。○を押すと「学習済み」の✓になり、もう一度押すと取り消せます。「すべて／未学習／学習済み」で選んだ級の一覧を絞り込めます。「前の20語」「次の20語」で進み、グループ末尾の「この20語を練習」で、そのグループだけを出題します（最後の短いグループは実際の語数）。問題形式を変えても対象のグループを保ち、途中の答えと得点を保存します。結果から「次のグループを学ぶ」へ進めます。通常のランダム10問、グループ練習、復習は別々に保存します。

毎日の新しい単語の目標は10語か20語を選べます。初めて学習済みにした日を端末の現地日付で記録し、今日の新しい単語と復習件数を表示します。同じ語を何度押しても重複計上せず、過去に学習した語をもう一度チェックしても新しい語には数えません。目標に届くと達成メッセージを表示します。

間違えた単語は次の練習や再読み込み後も残ります。「今日の復習」は今日が期日の語を最大10語ずつ出題します。結果画面の「今回の間違いだけ復習」は、その回の間違いをすぐに確認できます。最初の正解で本日通過とし、翌日、さらに3日後、7日後の復習を経て、4回目の期日で正解すると習得とします。同日や期日前に繰り返しても段階は進まず、もう一度間違えると今日の復習へ戻ります。日付は端末の現地日付で計算します。以前から保存されている錯語も引き継ぎます。

進度と間違えた単語は同じ端末・同じブラウザで利用できます。自動同期はありませんが、「学習設定 → 学習記録のバックアップ」で JSON ファイルを書き出し、別の端末へ移せます。読み込みは内容の件数を確認してから明示的に確定し、現在の記録を置き換えます。キャンセルや不正なファイルでは記録を変更しません。ブラウザの保存データを消去すると進度も消えます。保存が許可されていない環境でも、そのページを開いている間は学習できます。

単語一覧や振り返りの行は、文字や余白をタップして中国語の音声を再生できます。中国語が表示される問題カードも同じ操作で再生でき、もう一度タップすると停止します。別の単語をタップすると音声が切り替わり、再生中の行・カードに色が付きます。スピーカーボタンも引き続き使え、キーボードではボタンに移動して Enter または Space で操作できます。スクロールや文字の選択だけでは再生しません。

「まとめて聞く」では、表示中のグループを順番に再生できます。各語1回／2回、発音練習の間隔0～3秒を選び、一時停止・再開・前後の単語移動を操作できます。ページを開くだけでは再生せず、「このグループを聞く」を押して開始します。別の単語を直接聞く、級・画面・グループを切り替える、検索や並び順を変えるとグループ再生は停止します。

HSK 1 のピンイン順の最初の20語には「例文」を用意し、短い中国語文・ピンイン・日訳を開いて読めます。同じ例文を対応する誤答後にも確認できます。例文データは `data/examples.js` に分離しています。

音声ファイルは `audio/00/` ～ `audio/99/` に分けて保存し、各フォルダーは100ファイル以下です。通常のファイル名は見出し語です。読みが異なる多音字6組と「地／行」の修正には、語彙IDごとの独立した音声14本を使用します。追加分は明示的な発音指定による合成音声です。軽声の「过／得」は短い例「去过／说得好」で読み、画面にもその説明を表示します。修正内容・生成方法・出典・検証範囲は [発音監査記録](docs/pronunciation-audit.md) を参照してください。録音を追加した場合は `node tools/organize_audio.js` で所定のフォルダーへ配置できます。

`data/vocab.js` は教材ブックの語彙表 5003 語です。意味に紛れていた `Th` は「生」（都市・市場・市民では「市」）、`ft` は「当」、`ti` は「写」に戻してあります。同じ漢字でも読みや意味が違う行は、別の語として残しています。

語彙表を作り直すときだけ、次を実行します。

```
py -3 tools/import_vocab.py
node tools/build_vocab.js
node tools/audit_pronunciation.js
```

## 開発・動作確認

Node.js 20以上を使用します。

```sh
npm ci
npm test
```

検索・練習結果・キーボード操作・スマートフォン表示のブラウザテストは、別のターミナルで静的サーバーを起動してから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

```sh
npx playwright install chromium
npm run test:browser -- /tmp/hsk-browser-results
npm run test:continuity -- /tmp/hsk-continuity-results
npm run test:learning -- /tmp/hsk-learning-results
```

クラウド環境の既存Chromiumを使う場合、ブラウザの追加ダウンロードを省き、`HSK_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser -- /tmp/hsk-browser-results` を実行します。配信先は `HSK_BASE_URL` で変更できます。テストは一時的なブラウザコンテキストを使用し、ログとスクリーンショットを指定ディレクトリに保存します。
