# HSK語彙（1級–6級）

日本語で HSK 1級から 6級の語彙を学ぶ静的ページです。サーバーは要りません。`index.html` をブラウザで開いてください。

級のボタンで、いま学ぶ級を一つ選びます。「単語」と「練習」は別の画面です。練習画面では三つの問題形式を切り替えられます。単語一覧も練習も、その級の語だけです。

「学習設定」で再生速度を0.5～1.5倍に変更できます。ピンインは初期状態で非表示、日本語訳は表示です。表示設定は単語一覧と補助情報に適用され、問題に必要な題文と選択肢は常に表示されます。設定はこのブラウザに保存されます。

単語は中国語・ピンイン・日本語訳で検索できます。`zuotian` のように声調や空白を省いたピンインでも検索でき、検索結果の件数を表示します。検索内容は画面を切り替えても級ごとに保持されます（ページを再読み込みすると解除されます）。

単語一覧の「表示順」で「ピンイン順」か「ランダム順」を選べます。初期状態は声調を区別しないピンイン順です。選んだ表示順はこのブラウザに保存されます。ランダム順は級ごとに保持され、検索や画面の切り替えで変わりません。「再シャッフル」で並べ直せます。ページを再読み込みしても同じランダム順で続けられます。

練習は三つです。

- 意味を選ぶ：中国語を見て、日本語の意味を四つから選ぶ
- 中国語を選ぶ：日本語を見て、中国語を四つから選ぶ
- ピンインを選ぶ：中国語を見て、ピンインを四つから選ぶ

通常の練習は1回10問です。最後に「結果を見る」を押すと正解数と間違えた単語を確認でき、音声を聞いて復習できます。「もう一度、10問」で次の練習を始めます。

学習位置・級・練習の回答と得点はこのブラウザに保存されます。単語を調べたり、別の級や問題形式に切り替えたりしても、戻ると前の練習を続けられます。再読み込み後は前回の画面が開き、「続きから学ぶ」で学習位置へ移動できます。練習を最初からやり直す場合は「新しく10問を始める」を押し、確認してから始めます。

単語一覧は20語ずつのグループで表示します。✓を押すと「学習済み」になり、もう一度押すと取り消せます。各グループの学習済み件数と「前の20語」「次の20語」で、少しずつ進められます。検索はグループに関係なく、選択中の級全体から探します。

間違えた単語は次の練習や再読み込み後も残ります。メニューの「間違えた単語を復習」では選択中の級の間違えた単語を最大10語ずつ練習できます。結果画面の「今回の間違いだけ復習」なら、その回の間違えた単語だけを出題します。選択肢は同じ級の語彙から作られ、復習で正解した単語は待機中の間違えた単語から外れます。通常の練習と復習は別々に進度を保存します。

進度と間違えた単語は同じ端末・同じブラウザで利用できます。別の端末への同期には対応していません。ブラウザの保存データを消去すると進度も消えます。保存が許可されていない環境でも、そのページを開いている間は学習できます。

単語一覧や振り返りの行は、文字や余白をタップして中国語の音声を再生できます。中国語が表示される問題カードも同じ操作で再生でき、もう一度タップすると停止します。別の単語をタップすると音声が切り替わり、再生中の行・カードに色が付きます。スピーカーボタンも引き続き使え、キーボードではボタンに移動して Enter または Space で操作できます。スクロールや文字の選択だけでは再生しません。

音声ファイルは `audio/00/` ～ `audio/99/` に分けて保存し、各フォルダーは100ファイル以下です。ファイル名は見出し語と同じです。同じ漢字で読みが違う行は、同じ音声を使います。録音を追加した場合は `node tools/organize_audio.js` で所定のフォルダーへ配置できます。

`data/vocab.js` は教材ブックの語彙表 5003 語です。意味に紛れていた `Th` は「生」（都市・市場・市民では「市」）、`ft` は「当」、`ti` は「写」に戻してあります。同じ漢字でも読みや意味が違う行は、別の語として残しています。

語彙表を作り直すときだけ、次を実行します。

```
py -3 tools/import_vocab.py
node tools/build_vocab.js
```

## 開発・動作確認

Node.js 20以上を使用します。

```sh
npm ci
npm test
```

検索・練習結果・キーボード操作・スマートフォン表示のブラウザテストは、別のターミナルで静的サーバーを起動してから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

```sh
npx playwright install chromium
npm run test:browser -- /tmp/hsk-browser-results
npm run test:continuity -- /tmp/hsk-continuity-results
```

クラウド環境の既存Chromiumを使う場合、ブラウザの追加ダウンロードを省き、`HSK_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser -- /tmp/hsk-browser-results` を実行します。配信先は `HSK_BASE_URL` で変更できます。テストは一時的なブラウザコンテキストを使用し、ログとスクリーンショットを指定ディレクトリに保存します。
