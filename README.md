# HSK語彙（1級–6級）

日本語で HSK 1級から 6級の語彙を学ぶ静的ページです。サーバーは要りません。`index.html` をブラウザで開いてください。

級のボタンで、いま学ぶ級を一つ選びます。「単語」と「練習」は別の画面です。練習画面では三つの問題形式を切り替えられます。単語一覧も練習も、その級の語だけです。

「学習設定」で再生速度を0.5～1.5倍に変更できます。ピンインは初期状態で非表示、日本語訳は表示です。表示設定は単語一覧と補助情報に適用され、問題に必要な題文と選択肢は常に表示されます。設定はこのブラウザに保存されます。

練習は三つです。

- 意味を選ぶ：中国語を見て、日本語の意味を四つから選ぶ
- 中国語を選ぶ：日本語を見て、中国語を四つから選ぶ
- ピンインを選ぶ：中国語を見て、ピンインを四つから選ぶ

各語の「聞く」で、その中国語の音声を再生します。音声ファイルは `audio/00/` ～ `audio/99/` に分けて保存し、各フォルダーは100ファイル以下です。ファイル名は見出し語と同じです。同じ漢字で読みが違う行は、同じ音声を使います。録音を追加した場合は `node tools/organize_audio.js` で所定のフォルダーへ配置できます。

`data/vocab.js` は教材ブックの語彙表 5003 語です。意味に紛れていた `Th` は「生」（都市・市場・市民では「市」）、`ft` は「当」、`ti` は「写」に戻してあります。同じ漢字でも読みや意味が違う行は、別の語として残しています。

語彙表を作り直すときだけ、次を実行します。

```
py -3 tools/import_vocab.py
node tools/build_vocab.js
```
