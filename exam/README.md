# HSK真題トレーニング（過去問・公式サンプル演習）

HSK 1級〜6級の公式サンプル問題および過去問（全54セット・4,591問）を、本番形式で解ける静的トレーニングページです。トップページの「📝 真題トレーニング（過去問・模試）」から開けます（URL：`exam/?level=N`）。

- **語彙辞書連携**：問題文・共通資料・リスニング原文の中国語をタップすると、HSK単語サイト（`../data/vocab.js`・`../audio/`）のピンイン・品詞・日本語訳を表示し、サイトの録音で発音を確認できます。
- **ビルド不要・外部ライブラリなし**：静的 HTML / CSS / JavaScript のみで動作します。

## 学習モード

1. **パート練習モード**：1問ごとに即座に正誤判定。不正解時は**日本語解説**（正解の理由・あなたの解答と正解の比較・文法ポイント・音声つきポイント語彙）を自動表示します。正解時も解説を折りたたんで確認でき、リスニング原文（スクリプト）・ピンイン補助・中国語タップ辞書もいつでも使えます。
2. **本番タイマー模試**：公式試験時間（40〜140分）のカウントダウンつきで通し演習。採点ボタンを押すと、公式配点換算（HSK 1–2は200点満点・120点合格圏、HSK 3–6は300点満点・180点合格圏）でセクション別スコアを表示し、間違えた問題には日本語解説がつきます。
3. **復習ノート**：練習モード・模擬試験で間違えた問題が級ごとに自動登録されます。解き直して習得したらリストから外せます。
4. **HSK 6級 要約トレーニング（第101問）**：10分間の本文読解タイマー終了後、本番どおり元の文章を隠して400字要約を書く練習ができ、書き終えたあとに原文を再表示して見比べられます。

## 記録とバックアップ

演習の解答状況・模試の最高得点・復習ノート・設定は、端末のブラウザの `localStorage`（`hsk-exam-progress-v1`・`hsk-exam-preferences-v1`）に保存されます。左メニューの「学習設定・バックアップ」から JSON ファイルでの書き出し・読み込みが可能です。

## ファイル構成

```
exam/
  index.html               画面（../js/hsk.js・../data/vocab.js・../js/study.js を読み込み）
  css/exam.css             スタイル（ライト／ダーク対応、レスポンシブ）
  js/exam-core.js          採点・公式スコア換算・日本語解説生成・語彙辞書マッチングの純粋ロジック
  js/exam.js               画面制御・音声プレイヤー・タイマー・復習ノート
  data/manifest.js         全54セットの目録
  data/sets/*.js           各セットの構造化問題データ＋日本語解説（必要時のみ遅延読み込み）
  data/explanations/*.json 全4,591問の日本語解説ソースデータ
  img/<SET_ID>/*.jpg       問題・選択肢・本文の図版
  audio/<SET_ID>.mp3       精簡モノラルMP3リスニング音声（48セット分）
```

テスト：`npm run test:exam`（全54セット・4,591問の構造・正答・日本語解説・画像・音声ファイル検証および採点ロジック検証）、`npm run test:exam-browser -- <出力フォルダ>`（ブラウザE2E検証）。
