# 汉字勇者（かんじゆうしゃ）— HSK ことばの冒険RPG

HSK単語サイトの中に入っている、RPG 形式の単語練習ゲームです。学生が **HSKの級とことばをえらび**、えらんだことばが戦闘で**何度もくりかえし**出てきます。
サイトのトップページの「🗺️ RPGで冒険（汉字勇者）」から開けます（URL：サイトの `rpg/?level=N`。サイトで選んでいる級で始まります）。

- **単語・音声はサイトと同じデータ**です。`../data/vocab.js`（単語）、`../audio/`（録音、場所は `../js/hsk.js` の `HSK.audioPlaybackSrc`）、`../game/js/`（多音字・同じ意味の選択肢をさける出題：HSKもじバトルと共通）を読み込みます。`rpg/` の中に単語や録音のコピーはありません。サイトの単語・録音を直すと、RPG にもそのまま反映されます。
- ビルド不要・外部ライブラリなし。

## ものがたり
わすれんぼう大王に、村のことばをうばわれてしまった！ 草原・森・洞窟・城の4つの場所でことばのモンスターと戦い、4つの宝珠を取りもどそう。

## ことばをえらぶ
「はじめから」のあと、まず **HSKの級（1〜6）** と **ことば** をえらびます。あとから村の王先生、またはメニューの「ことば」でえらびなおせます。
- **サイトで学習中の20語**：サイトの単語一覧でいま開いている20語（ピンイン順でもランダム順でも、サイトと同じ20語）。はじめて遊ぶときは、最初からこれがえらばれています。
- **サイトでまちがえた単語**：サイトの練習でまちがえて、まだ習得していない単語（その級の分）。
- **グループ**：サイトの単語一覧と同じ、声調を区別しないピンイン順の20語ずつ（例：HSK2 の「21–40」）。▾ で1語ずつえらべます。
- **★が少ないことば**：RPG で★が少ないことば（最大20語）。
- 4語以上。おすすめは10〜40語。少ないほど、同じことばが多く出ます。

サイトの記録（`hsk-study-progress-v1`・`hsk-study-preferences-v1`）は読むだけで、変更しません。

## くりかえしのしくみ
戦闘・先生の練習では、**えらんだことばだけ**が出ます（選択肢も、できるだけえらんだことばから作ります）。
- 1回の戦闘でだいたい4問。1問目と3問目は、まだ見つけていないことば（最初に単語カード：漢字・ピンイン・意味・音声）。
- それ以外は、えらんだことばの中で「いちばん待っている」ことばから出します。まちがえた・新しく覚えたことばは**2問あとにもう一度**。正解したことばは★に応じて間をあけます（★0：えらんだ語数の半分あと〜★3：1.5倍あと）。
- ★（0〜3）は**間をあけて正解**するとふえ、まちがえるとへります。
- ボスの条件：草原＝全部見つける、森＝全部★1以上、洞窟＝全部★2以上、城＝全部★3。先へ進むほど、同じことばを何度も正解する必要があります。

問題の種類：漢字→意味／意味→漢字／漢字→ピンイン／リスニング／声調（ボス戦）。日本語の意味に同じ漢字がそのまま入っている語（北京＝北京、学校＝学校 など）は、ピンインかリスニングで出します。

## あそびかた
| | パソコン | スマホ・タブレット |
|---|---|---|
| 歩く | 矢印キー／WASD、または行きたい場所をクリック | 十字ボタン（指をすべらせて向きをかえられる）、または地図をタップ |
| 話す・調べる・決定 | Enter／スペース／Z、または人・宝箱をクリック | A ボタン、または人・宝箱をタップ |
| メニュー | M／Esc、または右上の「≡ メニュー」 | 右上の「≡ メニュー」 |
| 戦闘 | 1〜4キーで解答、スペースで音声をもう一度 | 答えをタップ |

各地の**先生**は新しいことばを5つずつ（1語2回の練習つき）、村の**王先生**は★の少ないことばのふくしゅう（10問）。お店・宿屋・宝箱・装備・レベルアップ・ことば図鑑があります。

## 端末・ブラウザ
- スマホ縦：地図の下に十字ボタンと A ボタン。スマホ横：十字ボタン｜地図｜A ボタン（戦闘は左に敵、右に問題）。タブレット・パソコン：画面に合わせて大きい地図（パソコンではボタンをかくして、キーの説明を表示）。
- ドット絵は画面の実際のピクセル数でかいてから表示するので、どのブラウザ・どの画面でもぼやけません。
- 画面の十字ボタン・A ボタンは、タッチできる端末で自動的に出ます（メニューの「せってい」で変更可）。全画面ボタンは対応しているブラウザだけ（iPhone の Safari は非対応）。
- 中国語には `lang="zh-CN"`（簡体字の字形）。ピンインは声調記号つきの母音（ǎ ǐ ǒ ǔ ǖ ǘ ǚ ǜ）を持っている欧文フォントで表示します。
- LINE などアプリ内ブラウザでは、Safari／Chrome で開きなおすようにタイトル画面でお知らせします。`confirm()` は使わず、ゲーム内の確認ボックスを使います。
- 更新したときは、`rpg/index.html` の `?v=…` を変えてください（スマホに古い CSS・JS が残らないように）。

## 記録
端末のブラウザの `localStorage`（キー `hskRpg.v1`）に自動で保存します。サーバーには何も送りません。

## ファイル
```
index.html        画面（../js/hsk.js・../data/vocab.js・../game/js/ を読み込む）
css/style.css     見た目
js/words.js       サイトの単語を、サイトと同じピンイン順・20語のグループにまとめる（録音は ../audio/）
js/world.js       地図・人・宝箱・エリア・モンスター・アイテム・会話
js/sprites.js     ドット絵（このゲームのためのオリジナル）
js/rpg.js         ゲーム本体（移動・会話・戦闘・ことばのくりかえし・サイトの学習記録を読む・メニュー・セーブ）
```
テスト（リポジトリの `test/`）：
- `npm run test:rpg`：地図（人・宝箱・出口に届くか）、級とグループがサイトの単語一覧と同じか、全5003語の問題と録音、サイトのファイルを読み込んでいるか
- `npm run test:rpg-browser -- <出力フォルダ>`：サイト⇄RPG のリンク、サイトで学習中の20語（ピンイン順・ランダム順）とまちがえた単語、授業→戦闘（えらんだことば以外が出ない・全部がくりかえし出る）→ボス、サイトの録音、記録
- `npm run test:rpg-devices -- <出力フォルダ>`：スマホ縦横・タブレット・パソコンの13種類の画面で、表示が収まるか、クリック／タップ／十字ボタンで動けるか

ブラウザのテストは `HSK_BASE_URL`（なければ `http://127.0.0.1:8000/`）のサイトに対して行います。公開サイトの確認（`.github/workflows/verify-pages.yml`）でも実行されます。
