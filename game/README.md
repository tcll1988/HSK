# HSKもじバトル（汉字大战）— HSK単語バトルゲーム

HSK単語サイトの中に入っている、ドット絵風の単語練習ゲームです。正解すると攻撃が出て、まちがえるとHPが減ります。
サイトのトップページの「🎮 ゲームで単語バトル」から開けます（URL：サイトの `game/?level=N`。サイトで選んでいる級でゲームが始まります）。

- **単語はサイトと同じデータ**（`../data/vocab.js`）。漢字・ピンイン・日本語の意味は、サイトの表記をそのまま使っています。ゲーム側で単語を直すことはしません。
- **音声はサイトと同じ録音**（`../audio/NN/*.mp3`）。ファイルの場所はサイトの `js/hsk.js`（`HSK.audioPlaybackSrc`）で決めているので、サイトの録音を差し替えるとゲームにも反映されます。ブラウザの読み上げ（speechSynthesis）は使っていません。
- ビルド不要・外部ライブラリなし。

## あそびかた
1. タイトルで **HSK1〜6級** を選び、「はじめる」を押します。最初の一回だけチュートリアル（5問・ダメージなし）があります。
   開く級は ① URLの `?level=1〜6` ② このゲームの記録 ③ HSK単語サイトで選んでいた級（`hsk-study-progress-v1`）の順で決まります。
2. ステージは級ごとに自動で作られます（1ステージ12〜16語）。
   - HSK1（148語）：テーマ別の11ステージ
   - HSK2〜6：サイトの単語一覧と同じピンイン順で、約14語ずつ（HSK2：11、HSK3：21、HSK4：42、HSK5：94、HSK6：180ステージ）。ステージ選択は20ステージずつのページ表示で、上下のプルダウン（1〜20／21〜40…）から好きな範囲へ移れます。カードには最初の数語の漢字と、ピンインの範囲が出ます。
3. 1ステージの流れ：ザコ敵（漢字→意味／漢字→ピンイン／意味→漢字）→ 中ボス（3回正解で撃破、HP+1）→ ボス（リスニングと声調、5回正解で撃破）。まちがえた単語は、後半に別の形式でもう一度出ます。
4. HPは5。まちがえるか時間切れ（ザコ15秒・ボス20秒、設定でオフ可）で1減ります。まちがえたときは正解と「あなたの答え」を出して止まり、「つぎへ ▶」（Enter／スペースでも可）で進みます。正解のときは約1秒で自動的に進みます。
   3・5・10コンボでバナーが出ます。正解・ミスの効果音は設定でオフにできます。
5. HSK1はボスを倒すと次のステージが解放されます。HSK2〜6はチュートリアルのあと、すべてのステージを自由に選べます。
6. 「まちがえた単語を復習」は、いま選んでいる級でミスの多い単語（最大12語）のステージです（記録がない級では押せません）。
7. ポーズ（Ⅱ／Escキー）中は、タイマー・次の問題への進行・音声がすべて止まります。

音声が出る場面：リスニング問題（大きな🔊をタップするともう一度。スペースキーでも可）、答えたあと（設定でオフ可）、問題の漢字をタップしたとき、結果画面の🔊。
録音が「例の語句」になっている語（サイトの `audioText`、例：次→一次）は、リスニング問題には出しません。
録音が読み込めないときは「音声を読み込めませんでした」と表示し、リスニング問題はピンインで出題します（ゲームは止まりません）。

選択肢の作り方（`js/questions.js`）：
- ピンイン・声調問題の「まちがい」の選択肢には、その漢字のほかの正しい読み方を出しません（vocab.js の全級の読み、1文字語は pypinyin の多音字の読み〔`js/readings.js`〕、好hào・少shào・教jiào・看kān・为wéi・只zhī など、一・不 の変調形 yí/yì/bú）。
- 読み方が2つ以上ある1文字の語（好・少・一・不・看 など）には声調問題を出さず、ピンイン問題にします。
- 意味の問題では、意味を「、」などで区切って比べ、同じ意味・重なる意味の選択肢を並べません（答えと同じ漢字のほかの見出しの意味もふくめて比べます）。
- 単語・ピンイン・意味・録音のデータ自体はここでは変えていません。
iPhoneでは、最初のボタン操作のときに音声を有効にしています。
端末で「視差効果を減らす」（prefers-reduced-motion）がオンのときは、画面のゆれ・フラッシュを出しません。

## 記録
端末のブラウザの `localStorage`（キー `hskMojiBattle.site.v1`）に、級ごとのクリア状況・ベストスコア・まちがえた単語と、設定を保存します。サーバーには何も送りません。

## ファイル
```
index.html       画面（../js/hsk.js と ../data/vocab.js を読み込む）
css/style.css    見た目
js/pinyin.js     サイトのピンイン（声調記号つき）を音節に分ける・声調ちがいの選択肢を作る
js/readings.js   1文字語の多音字の読み（tools/build_game_readings.py で vocab.js から生成）
js/questions.js  問題と選択肢を作る（多音字・同じ意味の選択肢をさける）
js/levels.js     級ごとの単語・ステージ・音声ファイルの場所
js/art.js        ドット絵（このゲームのためのオリジナル）
js/game.js       ゲーム本体
```
テスト：`npm run test:game`（単語・ピンイン・全録音ファイルの対応、全級の全単語で問題を何度も作り、ほかの読み方・重なる意味の選択肢が0件であること）、`npm run test:game-browser -- <出力フォルダ>`（ブラウザでチュートリアル〜ボスまで）。
