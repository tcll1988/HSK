# HSKもじバトル（汉字大战）— HSK単語バトルゲーム

HSK単語サイトの中に入っている、ドット絵風の単語練習ゲームです。正解すると攻撃が出て、まちがえるとHPが減ります。
サイトのトップページの「🎮 ゲームで単語バトル」から開けます（URL：サイトの `game/`）。

- **単語はサイトと同じデータ**（`../data/vocab.js`）。漢字・ピンイン・日本語の意味は、サイトの表記をそのまま使っています。ゲーム側で単語を直すことはしません。
- **音声はサイトと同じ録音**（`../audio/NN/*.mp3`）。ファイルの場所はサイトの `js/hsk.js`（`HSK.audioPlaybackSrc`）で決めているので、サイトの録音を差し替えるとゲームにも反映されます。ブラウザの読み上げ（speechSynthesis）は使っていません。
- ビルド不要・外部ライブラリなし。

## あそびかた
1. タイトルで **HSK1〜6級** を選び、「はじめる」を押します。最初の一回だけチュートリアル（5問・ダメージなし）があります。
2. ステージは級ごとに自動で作られます（1ステージ12〜16語）。
   - HSK1（148語）：テーマ別の11ステージ
   - HSK2〜6：サイトの単語一覧と同じピンイン順で、約14語ずつ（HSK2：11、HSK3：21、HSK4：42、HSK5：94、HSK6：180ステージ）。ステージ選択は20ステージずつのページ表示です。
3. 1ステージの流れ：ザコ敵（漢字→意味／漢字→ピンイン／意味→漢字）→ 中ボス（3回正解で撃破、HP+1）→ ボス（リスニングと声調、5回正解で撃破）。まちがえた単語は、後半に別の形式でもう一度出ます。
4. HPは5。まちがえるか時間切れ（ザコ15秒・ボス20秒、設定でオフ可）で1減ります。
5. ボスを倒すと、その級の次のステージが解放されます。
6. 「まちがえた単語を復習」は、いま選んでいる級でミスの多い単語（最大12語）のステージです。

音声が出る場面：リスニング問題、答えたあと（設定でオフ可）、問題の漢字をタップしたとき、結果画面の🔊。
録音が「例の語句」になっている語（サイトの `audioText`、例：次→一次）は、リスニング問題には出しません。
録音が読み込めないときは「音声を読み込めませんでした」と表示し、リスニング問題はピンインで出題します（ゲームは止まりません）。
iPhoneでは、最初のボタン操作のときに音声を有効にしています。

## 記録
端末のブラウザの `localStorage`（キー `hskMojiBattle.site.v1`）に、級ごとのクリア状況・ベストスコア・まちがえた単語と、設定を保存します。サーバーには何も送りません。

## ファイル
```
index.html       画面（../js/hsk.js と ../data/vocab.js を読み込む）
css/style.css    見た目
js/pinyin.js     サイトのピンイン（声調記号つき）を音節に分ける・声調ちがいの選択肢を作る
js/levels.js     級ごとの単語・ステージ・音声ファイルの場所
js/art.js        ドット絵（このゲームのためのオリジナル）
js/game.js       ゲーム本体
```
テスト：`npm run test:game`（単語・ピンイン・全録音ファイルの対応）、`npm run test:game-browser -- <出力フォルダ>`（ブラウザでチュートリアル〜ボスまで）。
